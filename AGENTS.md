Vietnamese (Northern / Hà Nội) is the first ready language, built on the VTV drama *Về nhà đi con* (回家吧，孩子), with a 12-week short track and a 5-year long track on the same 82 parts. The English catalog includes *Friends* S01–S02, *Seinfeld* S01–S02, *Silicon Valley* S01 and *Desperate Housewives* S01, all text only (no audio/video/clips). Japanese starts with *逃げるは恥だが役に立つ* and French starts with *Lupin* (France French before a planned Québec pick). Both are text only. Spanish (Mexican / Latin-American) has *Club de Cuervos* S04 (short-track pick; S01–S03 have no Spanish subtitles on SubDL, so only S04 is included) and *La casa de las flores* S01–S02 (long-track pick), text only, with a Spain-Spanish show planned later. Cantonese is a placeholder with a planned pick in `site/lib/catalog.js`. Owner: Alan. Live: https://tv.alanzhu.dev (production), https://tv-preview.alanzhu.dev (preview).

## Hard rules
- **Nothing copyrighted in Git.** Transcripts, bilingual SRTs, phrase cards with show lines and audio clips live only in `site/private/` (git-ignored) and are deployed behind Cloudflare Access. Public Git may hold code, the episode list (`data/ve-nha-di-con/parts.json`: public YouTube IDs/titles) and our own teaching content.
- `/private/*` is protected twice: Cloudflare Access apps "TV study private" (`tv.alanzhu.dev/private`) and "TV study private (preview)" (`tv-preview.alanzhu.dev/private`), each using the dedicated policy "TV study: Alan + Linh via Google" (the two allowed Google accounts only; emails live in Cloudflare, never in Git); and `src/worker.js` re-verifies the Access JWT (`ACCESS_AUD` per env in `wrangler.jsonc`). Never set `workers_dev` or `preview_urls` to true, never widen the Access policy, never delete Access apps.
- No secrets in code, logs, commits or chat. Translation and phrase extraction use subscription CLIs by default (`pipeline/llm.py`: Claude Code `haiku`, then Codex `gpt-6-luna`, rotating on rate limits). Paid DeepSeek/GLM HTTP APIs are off unless `LLM_ALLOW_PAID=1` and a key is set; never print keys. Development and review stay in different tools (Codex/Claude Code implement; agy reviews).
- Video source is the **VFC Official** playlist `PLdilN7V0FSOGDiPmg4MVIjP9dfLm0qxWA`, reversed into story order P01–P82. SRT timings only match these uploads.
- Deploy production only when asked: `npx wrangler deploy`. Preview: `npx wrangler deploy --env preview`. Both upload `site/private/` from the local machine, so build it first with `python3 pipeline/build_site_data.py WORKDIR`. Private assets use Worker static assets under `/private/*` (no R2 unless a later change is approved; stop if a paid plan would be required).
- Long pipeline jobs on the shared box must be started with `setsid nohup` so they survive agent interruptions. Do not restart or kill a live `cut_clips.py` / `clip_worker2.sh` / `finalize_preview.sh`.

## Layout
- `site/` static app (vanilla ES modules, hash routes). `site/lib/catalog.js` (languages, shows, routes and legacy aliases), `site/lib/curriculum.js` (12-week / 84-day short plan), `site/lib/long-curriculum.js` (260-week / 6-stage long plan), `site/lib/srs.js` (SM-2 style SRS), `site/lib/pron.js` (week-1 lessons), `site/lib/motion.js` (page transitions, reduced-motion), `site/lib/show-curriculum.js` (short/long plans for multi shows), `site/multi.js` (views for multi shows), `site/lib/i18n.js` + `site/lib/prefs.js` (zh/vi UI, per-user defaults), `site/shows/<id>/episodes.json` (public episode lists). `site/vlc.html` and `site/download.html` are public zh tutorials (VLC + bilingual SRT; downloading the official YouTube videos), routed as `#/<lang>/<show>/vlc|download` with aliases `#/vlc`, `#/download`. `site/archive/5s-online/` = previous 5S Online + IT scenario app (frozen).
- `src/worker.js` Worker: serves assets, guards `/private/*`, serves `/private/me.json`.
- `pipeline/` data pipeline (Python 3, ffmpeg; faster-whisper + yt-dlp in a venv):
  1. `yt-dlp --write-auto-subs --sub-langs vi-orig --sub-format json3` per part (P06 has no captions → `whisper_to_json3.py`).
  2. `captions_to_bilingual.py CAPS.json3 gen/Pxx` → `Pxx.lines.json` + `Pxx.vi-zh.srt` (LLM regroup + fix + translate; `llm.py` = DeepSeek primary, GLM glm-4.6 fallback; `--reuse` re-times without LLM).
  3. `extract_phrases.py` → `Pxx.phrases.json` (LLM picks; `tones.py` and `reading.py` add tone marks and pinyin-style readings by rule).
  4. `cut_clips.py` pass 1: original-audio clips (line span, pad 0.3/0.5 s, ≤ 6 s), kept if Whisper hears ≥ 60 % of the phrase syllables. Pass 2 (`--mode window --min-score 0.75`): only phrases still missing a clip; locate the phrase with word timestamps in a wider window.
  5. `build_site_data.py WORKDIR` → `site/private/{data,srt,audio}`.
- Work folder on the Grok box: `/workspace/tvshows-work/venhadicon/` (captions, audio, gen/). Helpers: `resume.sh`, `clip_worker2.sh`, `finalize_preview.sh`. Do not name work folders dist/build/out.

## Multi-show pipeline (`pipeline/multi/`)
Show config lives in `pipeline/multi/common.py` (`SHOWS`). Every step is re-runnable and skips existing output (`--only EP01,EP02` / `S01E01` / `1-5`, `--force` to redo). Python: `/home/box/venvs/ytdlp/bin/python`. WORKDIRs: `/workspace/tvshows-work/multi/dtt` (playlist.tsv, subs/, audio/) and `/workspace/tvshows-work/multi/friends` (srt/, episodes.json); outputs go to `WORKDIR/gen/`.
1. `ingest_youtube_json3.py SHOW WORK` (youtube-official): zh-Hans + vi share cues, en attached by max overlap → `CODE.lines.json` `{i,start,end,zh,py,vi,en}` (ms; pinyin by pypinyin, may miss polyphones).
2. `ingest_srt.py SHOW WORK` (text-only): `srt/SxxEyy.<target>.srt` → `{i,start,end,<target>}`. Japanese adds hiragana `reading` via `pykakasi` (install in the pipeline Python environment). Spanish cleanup drops `[música]` / `(risas)` cues, any cue with ♪ ♫ ♬ ♩ in any row (sung lyrics, dropped whole), rows wrapped in `# … #`, and ALL-CAPS `NOMBRE:` speaker labels; it keeps `¿ ¡` and `#` inside dialogue (`#Metoo`, `No. #20`). `fetch_addic7ed.py SHOW_SLUG SEASON LANG WORKDIR` can fetch completed original SRTs into that layout. `fetch_subdl.py SHOW WORK [--lang ES] [--dry-run]` fetches from SubDL using the show's `subdlTmdbId` / `subdlSeasons` (/ `seasonEpisodes`): the API key comes only from env `SUBDL_API_KEY` (never print or store it; URLs returned by the API carry it, so their query strings are stripped; upstream release/file/member names are redacted and reduced to safe characters at every output, and archive errors never include member names). Only `--lang ES` is accepted. A configured `seasonEpisodes` count is authoritative. It prefers episode-level subs, then season-pack files, skips HI files, uses a raw (non-zip) body only when metadata names an eligible `.srt` for that episode and the file name ends in `.srt` with no other episode's SxxEyy marker (season-pack zips need an episode-named member; members are read only if their declared size fits and they are stored/deflated), accepts only `.srt` with ≥150 cues that read as Spanish (mislabeled Italian packs exist; CR-only line endings are normalised), falls through to the next candidate on 404 / oversized / unreadable files, stops the run on 401/403/429. It never re-downloads (existing SRTs; `subdl-rejected.json` holds opaque hashes of rejected files and of packs already inspected for an episode), charges both budgets before every HTTP attempt including retries (stops before 250 downloads, anonymous limit 300/day/IP; API 2,000 requests/day), caps bodies at 20 MB and members at 5 MB, follows redirects itself (each hop charged, at most 3, https `*.subdl.com` only, redirect bodies never read), drops unparseable URLs silently, rewrites a legacy plain-path `subdl-rejected.json` as hashes on load, and writes `WORK/subdl-manifest.json` without URLs.
3. `translate_lines.py SHOW WORK`: fills missing target translations in batches via `llm.py` (CLI backend). English and Chinese shows get `zh`+`vi`; Japanese, French and Spanish shows get `zh` only (Vietnamese lines are for Linh's zh/en study). Saves after every batch.
4. `extract_phrases_multi.py SHOW WORK`: ~15 cards/episode, level (HSK1–6/HSK7-9, CEFR, or JLPT N5–N1) and Japanese phrase readings, explanations in the show's `explainLangs` (`zh`+`vi` for zh/en shows, `zh` only for ja/fr/es; fr/es match whole words, es keeps ñ distinct from n). Phrases not found in the source line are dropped.
5. `cut_clips_cues.py SHOW WORK` (youtube-official only): mp3 per card from its cue (−0.25 s/+0.4 s, ≤ 7 s, mono 64 kbps); skips episodes whose audio is missing.
6. `build_show_data.py SHOW WORK` → `site/private/shows/<id>/{index.json, eps/CODE.json, srt/*.srt, audio/CODE/*.mp3}` (zh+vi and zh+en SRT for 都挺好; target+zh, and target+vi only when the show includes vi). Rebuilds only that show's folder.
   Re-ingesting (`--force`) can drop lines and renumber `i`. Copy the old `gen/*.lines.json` to a backup folder first, then run `reindex_phrases.py SHOW WORK --old-gen BACKUP [--only …] [--dry-run]`: it points each card's `line` at the new line with the same start, end and text, drops (and reports) cards whose cue is gone, never calls an LLM, is idempotent and prints `{episode: {kept, dropped}}`.
7. `episodes_public.py SHOW WORK` → `site/shows/<id>/episodes.json` (public: episode numbers, YouTube IDs, durations, titles; tracked in Git).
Text-only episode lists number only episodes with an existing target-language SRT, skipping gaps in the source listings; when a show sets `seasonEpisodes`, SRTs outside those per-season ranges are ignored. Run `episodes_public.py` once the SRT set is ready. Set `LLM_USAGE_LOG=/path/usage.jsonl` to record token usage.

## Per-user defaults
`GET /private/me.json` (Worker, after the JWT check) returns `{visibleLangs, uiLang, explainLang, hideLangs, name}` from the secret `USER_PREFS` (JSON: lowercase email → prefs). The site default and Alan's profile use `hideLangs: ["vi"]` (Chinese translations only; Vietnamese study still shows Vietnamese as the target language plus Chinese). Linh's profile uses `hideLangs: []` so she sees Vietnamese translations on Chinese and English shows, with `visibleLangs: ["zh","en"]` and a Vietnamese UI (so the ja/fr/es cards stay hidden for her). Unknown users get `{null, "zh", "zh", ["vi"], null}`. The response never echoes the email. Set the secret with `npx wrangler secret put USER_PREFS` (and `--env preview`); never put emails in `wrangler.jsonc` or Git. `visibleLangs` and `hideLangs` are display only, not authorization. The UI (`site/lib/prefs.js`, `site/lib/i18n.js`) falls back to defaults for anonymous users; localStorage overrides via the header menu.
